# Local Water Quality Monitoring and Complaint Tracking System

A ward-level platform where residents view water-test records,
report problems, and track complaints. Admins manage tests and
complaints and see a hotspot map.

## Tech
HTML, CSS, JavaScript, Supabase, Leaflet (OpenStreetMap), Vercel

## Disclaimer
Status shown is informational, compared against selected BIS IS 10500
reference limits. It does not replace laboratory testing.
